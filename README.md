## Начать

1. Скачайте установщик, выберите папку и нужные ярлыки.
2. Запустите Voice, поставьте курсор в поле ввода и используйте **Mouse 5** или **Ctrl + Alt + Space**. Настройка активации доступна в трее.
3. Говорите по-русски и завершите запись. Voice вставит распознанный текст в выбранное поле.

Приложение, модель и .NET 8.0.30 включены в один EXE установщика. Диктовка работает без сети и отдельной видеокарты. Приложение — WPF/.NET; в этой поставке нет Electron, Whisper, Qwen или движка перевода.

## Изменения 2.4.2

- Микрофон по умолчанию Windows выбирается заново при начале записи; временный отказ устройства и ручная пауза учитываются отдельно.
- Операции захвата и завершения выполняются вне UI dispatcher. Скрытые/свёрнутые окна отключают лишние кадры и таймеры настроек.
- Исправлен запуск при отключённых анимациях Windows и сохранение громкости при быстром закрытии настроек.
- Сохранены GigaAM v3 INT8, CPU4 и проверенное оформление по аудио. Прирост акустической точности в процентах не заявляется.

## Сохранено из 2.4.0

- **Слова и оформление.** Plain GigaAM v3 RNNT сохраняет основной текст; E2E распознаёт то же аудио для пунктуации и заглавных букв. Один локальный профиль, по четыре CPU-потока на каждый этап.
- **Известные названия.** Правильное английское написание применяется только при безопасном подтверждении вторичной аудиомоделью. Обычные слова, неизвестные имена и структурированный текст не домысливаются.
- **Надёжность.** Исправлены пути с кириллицей, отмена и гонки инициализации. При временном отказе оформления слова остаются доступными, а интерфейс сообщает об этом.
- **Настройки.** Пунктуация включена по умолчанию; явный выбор выключить её сохраняется. Микрофон, тема, клавиши и история сохраняются при обновлении. Предзапись, окончания, тихая речь и плавная капсула сохраняют исправления 2.3.

На 80 публичных человеческих записях / 1169 слов ошибки пунктуации уменьшились **на 53,07%**, ошибки surface characters с учётом регистра и пунктуации — **на 57,94%**. Ошибок в словах осталось 26/1169. Медиана прогретого распознавания выросла примерно с 76 до 162 мс. Это не измерение личного голоса, трудных фонем, английских брендов или задержки от кнопки до вставки. [Методика и ограничения](docs/models/EVALUATION-2.4.0.md).

В 2.4.2 убраны лишняя копия короткой записи, повторное чтение результата движка и предзагрузка отключённых сигналов. На установленной версии за 45 секунд: CPU в среднем 0,011%, RAM около 1,13 ГБ, GPU 0% в наблюдении. Временные выделения C# снижены; уменьшение постоянной RAM и личный прирост точности не подтверждены.

## Данные и проверки

Аудио распознаётся на компьютере. При свежей установке история аудио выключена; ваш существующий выбор сохраняется. Данные находятся в `Data` рядом с приложением. Диагностические логи не содержат аудио и распознанного текста.

Проверены 1153 тестов полной редакции и 1146 теста Compact (7 проверок только для Full), нативное распознавание, визуальные состояния и транзакционный откат обновления. Установщик не подписан Authenticode; полный цикл в чистой Windows VM остаётся непроверенным. Ограничения прежнего Full Offline не объявляются закрытыми.
