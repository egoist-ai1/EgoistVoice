# Egoist Voice

Нативная локальная диктовка для Windows 10/11 x64. Версия `2.1.0` использует GigaAM v3 как основной русский движок и Whisper Large v3 Turbo как изолированный fallback для смешанной RU/EN речи: отказ одного движка не прерывает диктовку.

По умолчанию запись запускается удержанием `Mouse 5`; резервная комбинация — `Ctrl + Alt + Space`. Правый клик по иконке в tray открывает меню «Кнопка запуска», где можно выбрать Mouse 5, Mouse 4, клавиатуру, Mouse 5 вместе с клавиатурным резервом либо задать собственную глобальную клавишу/комбинацию. Боковая кнопка никогда не перехватывается и автоматически игнорируется, когда активным приложением является игра.

## Как это выглядит

Капсула появляется над панелью задач только на время диктовки и уходит сама. Всё нарисовано
векторно в WPF: ни одной растровой иконки, ни одного веб-компонента.

## Голосовая команда «переведи» (2.1.0, в работе)

Команда в начале или в конце фразы переводит надиктованное локальной моделью
HY-MT1.5-7B и вставляет уже перевод: «Переведи привет, как дела» → `Hi, how are
you?`. Формы: «переведи [это/всё]», «переведи на немецкий …», «… переведи
по-английски»; язык по умолчанию — английский. Модель делится с EGOIST
Translator через общий порт 47821 (кто первым поднял llama-server, тот владеет);
рантайм ставится скриптом `projects/egoist-translator/scripts/install-model.ps1`.
Если переводчик недоступен, вставляется оригинал без слова-команды. Подробности —
в `CHANGELOG.md`.

## Что входит

- GigaAM v3 e2e-RNNT INT8 через нативный sherpa-onnx: русский язык, пунктуация и нормализация.
- Whisper `large-v3-turbo-q5_0` с CUDA → Vulkan → CPU fallback для английских технических терминов и смешанной речи.
- Детерминированный селектор: чистый русский результат берётся из GigaAM, mixed RU/EN — из Whisper только когда тот объективно сохраняет больше латинских или известных технических токенов.
- Разбиение длинной записи по самым тихим границам на фрагменты до 22 секунд без генеративного переписывания слов.
- Тихий сеанс полностью пропускается: ASR, clipboard и вставка не запускаются.
- Компактная 48 px WPF-капсула с supersampled DPI-aware контуром, полноширинной 24-полосной audio-reactive waveform и поддержкой Reduce Motion/High Contrast. Окно фиксированного размера: ширина меняется у самой капсулы, а не у HWND, поэтому смена состояния не тянет за собой ресайз окна и перерисовку контура.
- Long-form распознавание показывает единое непрерывное состояние «Распознаю» без технической нумерации аудиофрагментов и без перезапуска анимации.
- HTTP Range-докачка с восстановлением после некорректного диапазона, SHA-256, проверка свободного места и атомарная активация всех компонентов модели.
- Модельные URL закреплены на проверенных ревизиях Hugging Face; чистая установка воспроизводима и не зависит от изменения ветки `main`.
- Настройка кнопки запуска, включая пользовательскую комбинацию, атомарно сохраняется в `%LOCALAPPDATA%\EgoistVoice\activation.json` и не сбрасывается при обновлении. Если Windows отклоняет новую комбинацию, приложение сохраняет прежнюю рабочую привязку.

## Установка

Скачать `EgoistVoice-Setup-2.1.0-win-x64.exe` со [страницы релизов](../../releases/latest) и запустить. Установщик в репозиторий не коммитится: он весит ~1,2 ГБ, потому что несёт в себе обе речевые модели и все runtime.

Компактный фирменный чёрно-красный установщик использует собственные растровые пиктограммы и не задаёт лишних вопросов: один клик останавливает старую версию, обновляет приложение и запускает Egoist Voice в системном tray. Поскольку модели уже внутри, чистая установка и первый запуск не требуют скачивания модельных файлов. Интернет остаётся нужен только для будущего обновления модели, если её версия изменится. Runtime-статусы используют заранее зафиксированные DPI-aware слоты, поэтому длинные подписи и проценты не обрезаются во время установки.

Windows SmartScreen покажет предупреждение: сборка не подписана EV-сертификатом. «Подробнее» → «Выполнить в любом случае».

### Сборка из исходников

Нужен .NET 8 SDK и [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```powershell
dotnet test .\Egoist.Voice.sln -c Release      # 293 теста
powershell -File .\scripts\release-2.0.ps1     # сборка + установщик, ~10 минут
```

`release-2.0.ps1` делает всё: self-contained публикацию, докачку моделей с Hugging Face по
закреплённым ревизиям со сверкой SHA-256 и упаковку в Inno Setup. Результат — в `artifacts\release`
вместе с файлом `.sha256`.

Если консоль отваливается по таймауту, тот же установщик собирается в фоне:
`build-installer-detached.ps1` запускает сборку и возвращает управление, `poll-installer.ps1` ждёт
её завершения.

Модели хранятся в `%LOCALAPPDATA%\EgoistVoice\Models\Speech`, сохраняются при обновлении и полностью удаляются при деинсталляции через Windows. После загрузки аудио и распознанный текст не покидают компьютер. Пакет self-contained: .NET, CPU, Vulkan и CUDA runtime входят в установщик; Python не требуется.

Поддерживаемая граница переносимости — Windows 10/11 x64. На машине без совместимой GPU приложение автоматически использует CPU; ARM64/x86, заблокированный системой микрофон и отсутствие доступа к источникам моделей не могут быть программно превращены в поддерживаемую конфигурацию.

## Что нового в 2.0

Полный разбор — в `docs/v2/`: аудит 1.6.5, сравнение с рынком, спецификация и дорожная карта.

**Надёжность.** Распознавание ушло с UI-потока — раньше нативный декод выполнялся на диспетчере и
через `LowLevelHooksTimeout` мог привести к тому, что Windows молча снимала хук Mouse 5. Сам хук
переехал на выделенный поток с собственным message loop и watchdog'ом, определение «активное окно
— игра?» стало дешёвым (`QueryFullProcessImageName` вместо перечисления модулей чужого процесса),
DPI объявлен как PerMonitorV2, капсула ограничивается рабочей областью того монитора, на котором
находится.

**Скорость.** Whisper больше не запускается на каждой диктовке: он подключается только когда в
выводе GigaAM есть латиница, узнаваемая русификация термина или явно включён смешанный режим. Для
чисто русской речи это убирает основную часть p95. Модель выгружается после 10 минут простоя.
Первая диктовка после старта больше не ждёт загрузки 574 МБ. Оба движка получают три четверти
логических ядер вместо половины — прежнее деление предполагало, что они считают одновременно.

**Смешанная речь.** Когда Whisper всё же подключается, язык не форсируется на русский: именно
принудительный `ru` заставлял его переписывать английские термины кириллицей — ровно ту поломку,
ради починки которой он и вызывается. Декодирование идёт beam search вместо жадного, контекст
между сегментами не переносится, а промпт перечисляет термины связной двуязычной фразой.

**Точность.** Пользовательский словарь с учётом русских окончаний, нормализация чисел и дат
(за тумблером), голосовые команды («новая строка», «запятая», «открыть скобку»), единое
абзацевание для обоих движков, починенная дедупликация на стыках длинных записей.

**Доставка текста.** Буфер обмена возвращается после вставки — но только если вы сами ничего не
скопировали в этот момент. В терминалы автоматически уходит `Ctrl+Shift+V`. В менеджеры паролей
текст не вставляется и даже не копируется.

**Взаимодействие.** Esc отменяет диктовку. Четыре звуковых сигнала (старт, стоп, вставлено,
ошибка) — их можно отключить. Ошибка перестала быть красной: брендовый красный означает работу,
янтарный — отказ. Отклонённая запись больше не исчезает молча, а говорит почему: «Микрофон
молчит», «Слишком тихо», «Слишком коротко».

**Термины пишутся латиницей из коробки.** Раньше словарь замен поставлялся пустым и наполнялся
только если пользователь сам находил `dictionary.json` — поэтому «гитхаб», «кодекс» и «клод код»
попадали в текст кириллицей. Теперь встроенный словарь на несколько десятков терминов работает
сразу, с учётом русских окончаний: «в гитхабе» → «в GitHub», «собрал докером» → «собрал Docker».
Замена детерминированная — 0,02 мс против 80 мс у нейронной коррекции и, что важнее,
предсказуемая. Список намеренно осторожен: «хром», «интел», «курсор» и «нода» в него не входят,
потому что съели бы «хромой», «интеллект» и обычную русскую речь — неверная замена посреди
предложения хуже пропущенной. Пользовательский словарь ложится поверх встроенного и может
переопределить любое правило, включая спорное «кодекс» → «Codex».

**Визуал.** Капсула переработана целиком. Красный контур больше не идёт ровной яркой линией по
периметру: он вспыхивает в середине и растворяется к концам. Волна вместо гребёнки из палок —
зеркальная кривая по 72 точкам с прозрачной серединой, свечением снизу и светлым гребнем сверху;
края растворяются маской. Все иконки — микрофон, галочка, знак ошибки — нарисованы линией той же
толщины, что и кривая, вместо глифов из шрифта; залитые красные диски под ними убраны совсем, как
и жёсткие вертикальные разделители: расстояние разделяет не хуже. Состояние читается по свечению и
контуру, а форма иконки отличает отказ от успеха помимо цвета. Тень стала настоящей размытой, а не тремя вложенными кольцами без размытия. Спиннер —
дуга с переменной скоростью вместо четырёх вращающихся точек. Waveform рисуется одним визуалом
без аллокаций на кадр, с гамма-коррекцией уровня и заметным разбросом яркости от центра к краям.
Кривые появления и исчезновения разведены по Fluent: вход замедляется, выход ускоряется. С третьей
секунды записи справа появляется таймер табличными цифрами.

Всё это настраивается через **трей → Настройки**; словарь открывается оттуда же.

## Замер качества

```powershell
# Приложение должно быть закрыто: диагностические режимы за mutex единственного экземпляра.
.\bin\Release\net8.0-windows\Egoist.Voice.exe --corpus-benchmark .\tests\corpus .\artifacts\bench\latest.json
```

Отчёт содержит WER/CER по наборам, p50/p95 воспринимаемой задержки и все гипотезы целиком.
`CorpusGateTests` сравнивает его с `baseline.json` и падает на регрессии. Как записать корпус —
`tests/corpus/README.md`. Корпус не входит в поставку: это ваш голос, и он не коммитится.

Визуальная регрессия — `scripts\v2-phase0-check.ps1`: отрисовывает все состояния капсулы и превью
трея в `artifacts\v2-phase0`. Приложение при этом должно быть закрыто (`scripts\stop-app.ps1`).

## Разработка

```powershell
dotnet build .\Egoist.Voice.sln -c Release
dotnet test .\Egoist.Voice.sln -c Release
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-installer.ps1
```

Технический журнал не содержит аудио и распознанного текста: `%LOCALAPPDATA%\EgoistVoice\Logs\app.log`.

## Приватность

Приложение не имеет сетевого кода, кроме загрузчика моделей: он ходит только на `huggingface.co`
по закреплённым в исходниках URL. Аудио и распознанный текст никогда не покидают машину —
телеметрии, аналитики и облачного ASR в проекте нет.

Вставка подавляется, когда фокус находится в поле пароля: `DeliveryPolicy` проверяет целевой
контрол и возвращает `SuppressedForSensitiveTarget`, а капсула показывает «Не вставляю в пароли».
