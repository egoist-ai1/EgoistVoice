# Установка Preview 2

[← На главную](../README.md) · [Руководство](USER-GUIDE.md) · [Все файлы релиза](https://github.com/egoist-ai1/EgoistVoice/releases/tag/v2.2.0-preview.2)

Windows 10 **1903+** или Windows 11, **x64**. ARM и 32-битная Windows не поддерживаются
этими пакетами. .NET включён: отдельная установка среды не нужна. Нужны микрофон и разрешение
Windows на его использование. GPU-драйвер устанавливается отдельно производителем устройства.
На слабом компьютере начните с Compact; Full с несколькими моделями требует заметно больше памяти.

## Compact RU — установщик

1. Скачайте [EgoistVoice-Setup-Compact-RU-2.2.0-win-x64.exe](https://github.com/egoist-ai1/EgoistVoice/releases/download/v2.2.0-preview.2/EgoistVoice-Setup-Compact-RU-2.2.0-win-x64.exe), **253,4 МБ**.
2. Запустите и выберите папку. Установка выполняется для текущего пользователя.
3. Откройте Egoist Voice Compact через меню «Пуск». Сеть для диктовки не нужна.

В папке программы — около **518,5 МБ**. Запуск после установки и ярлык рабочего стола
не включаются автоматически. Настройки Compact находятся в `Data` внутри папки программы.

## Compact RU — portable

1. Скачайте [Portable ZIP](https://github.com/egoist-ai1/EgoistVoice/releases/download/v2.2.0-preview.2/EgoistVoice-Portable-RU-2.2.0-preview.2-win-x64.zip), **283,8 МБ**.
2. Полностью распакуйте архив в папку, доступную для записи, например `D:\Apps\EgoistVoice`.
3. Запустите `Egoist.Voice.exe`. Не запускайте его прямо из окна архива.

Модели лежат в `Models`, настройки и данные — в `Data` рядом с EXE. Маркер
`egoist-voice.portable` должен оставаться рядом с программой. Для переноса скопируйте
всю папку при закрытом приложении. Portable не добавляет автозапуск или установочную запись.
Чтобы удалить его вместе с личными данными, закройте приложение и удалите эту папку.

Compact ориентирован на русский язык и CPU. Whisper, встроенная Qwen и переводчик в него
не входят. Меню может показывать настройки подключения текстового сервера, но сервер
в компактном архиве отсутствует.

## Full + Qwen — один EXE для начала установки

**Preview:** целостность комплекта проверена, но полный цикл установки, запуска и удаления
Full на чистой системе ещё не подтверждён. [Подробности проверки](releases/2.2.0-preview.2.md#ограничения-preview).

Скачайте [EgoistVoice-Full-Setup-2.2.0-preview.2.exe](https://github.com/egoist-ai1/EgoistVoice/releases/download/v2.2.0-preview.2/EgoistVoice-Full-Setup-2.2.0-preview.2.exe), **0,4 МБ**, и запустите.
Он скачает примерно **5,6 ГБ**, проверит SHA-256 каждого файла и откроет установку.
При обрыве сети повторный запуск продолжает загрузку. Для загрузки, распаковки и установки
заранее освободите **30 ГБ**; это запас для одновременно существующих временных файлов.

Включены GigaAM, Whisper large-v3-turbo Q5, текстовая Qwen3-4B Q4_K_M, Hy-MT2-1.8B Q8,
runtime llama.cpp, CPU/GPU-библиотеки и .NET. Обычная работа после установки не требует сети.
Для скорости Qwen желательно GPU с совместимым Vulkan-драйвером; скорость на CPU зависит от
компьютера, а двухсекундный бюджет автоматического оформления может завершаться возвратом исходника.

На свежей установке Qwen включена, сохранение аудио выключено. При обновлении ваши настройки
сохраняются: включите форматирование вручную в меню, если оно было отключено ранее.

## Полная версия без интернета

На компьютере с интернетом скачайте **все три части** одного архива:

1. [EgoistVoice-Full-Offline-2.2.0-preview.2.7z.001](https://github.com/egoist-ai1/EgoistVoice/releases/download/v2.2.0-preview.2/EgoistVoice-Full-Offline-2.2.0-preview.2.7z.001)
2. [EgoistVoice-Full-Offline-2.2.0-preview.2.7z.002](https://github.com/egoist-ai1/EgoistVoice/releases/download/v2.2.0-preview.2/EgoistVoice-Full-Offline-2.2.0-preview.2.7z.002)
3. [EgoistVoice-Full-Offline-2.2.0-preview.2.7z.003](https://github.com/egoist-ai1/EgoistVoice/releases/download/v2.2.0-preview.2/EgoistVoice-Full-Offline-2.2.0-preview.2.7z.003)

Положите части в одну папку. Откройте `.001` в [7-Zip](https://www.7-zip.org/) и распакуйте;
остальные части будут прочитаны автоматически. Перенесите распакованную папку на нужный ПК
и запустите `EgoistVoice-Full-Setup-2.2.0-preview.2.exe`. Все данные уже рядом: загрузка не нужна.
Архив содержит установочный комплект, инструкции, лицензии и контрольные суммы; Full не является portable.

Можно обойтись без архива: скачать этот EXE, `EgoistVoice-Full-2.2.0-preview.2-inner.exe`
и все три `inner-1.bin`, `inner-2.bin`, `inner-3.bin` из релиза, положить вместе и запустить
верхний EXE. Он предпочитает соседние файлы и проверяет их перед запуском.

Один файл GitHub Releases должен быть [меньше 2 ГиБ](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases#storage-and-bandwidth-quotas),
поэтому большие пакеты разделены. Не смешивайте части разных версий и не переименовывайте их.

## Проверка SHA-256

Скачайте [SHA256SUMS.txt](https://github.com/egoist-ai1/EgoistVoice/releases/download/v2.2.0-preview.2/SHA256SUMS.txt)
и сравните хеш выбранного файла:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\EgoistVoice-Full-Setup-2.2.0-preview.2.exe'
```

Несовпадение означает, что файл повреждён или относится к другой сборке. Получите его заново
из этого релиза. Файлы **не подписаны Authenticode**; неизвестный издатель ожидаем, но SHA-256
не заменяет доверие к источнику. Отключать системную защиту для установки не нужно.

## Обновление, удаление и откат

Перед обновлением завершите Voice через меню. Установщик Full Preview 2 сохраняет ваши
настройки, словарь, историю и кэш моделей ASR/Qwen. В обычной установке данные находятся в
`%LOCALAPPDATA%\EgoistVoice`; сам Voice — в `%LOCALAPPDATA%\Programs\Egoist Voice`.
Общий движок расположен в `%LOCALAPPDATA%\EGOIST\TranslationEngine`.

Удаление Full убирает программу и её owner общего движка. Модели и пользовательские данные
остаются для повторной установки. Если установлен Translator, его owner и общий движок
сохраняются. Не удаляйте общую папку вручную, пока она нужна другому приложению.

Для обновления portable распакуйте новую версию в новую папку и, при необходимости,
перенесите только собственный `Data` из закрытой старой версии. Сохраните старую папку,
чтобы вернуться к ней. Для отката установленной Full заранее скопируйте пользовательские
данные, удалите Preview 2 и установите [нужный прежний релиз](https://github.com/egoist-ai1/EgoistVoice/releases).
Старые установщики могут иметь другую политику очистки данных; резервная копия обязательна.
