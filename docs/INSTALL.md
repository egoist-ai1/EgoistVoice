# Установка Egoist Voice 2.2.1

[← На главную](../README.md) · [Руководство](USER-GUIDE.md) · [Релиз](https://github.com/egoist-ai1/EgoistVoice/releases/tag/v2.2.1)

Windows 10 **1903+** или Windows 11, **x64**. Нужны микрофон и разрешение Windows
на его использование. .NET и русская модель включены, отдельная видеокарта не нужна.

## Установка

1. Скачайте [установщик 2.2.1](https://github.com/egoist-ai1/EgoistVoice/releases/download/v2.2.1/EgoistVoice-Setup-Russian-2.2.1-win-x64.exe), около **353 МБ**.
2. Закройте прежний Voice через значок в трее. Запустите новый EXE.
3. Выберите папку, автозапуск и ярлык рабочего стола. Нажмите «Установить».
4. После завершения нажмите кнопку запуска Voice. Если установщик сообщил о необходимости перезагрузки, выполните её вручную.

Установка выполняется для текущего пользователя. Папка по умолчанию:
`%LOCALAPPDATA%\Programs\Egoist Voice Compact`. Новый интерфейс сохраняет установочную
идентичность Compact и использует найденную папку предыдущей установки.

Внутри EXE — Voice, GigaAM INT8 и self-contained .NET 8.0.30. Установка и обычная
русская диктовка работают без сети. React/Electron нужен только установщику.
Qwen, Whisper, Hy-MT и общий движок перевода не включены.

## Обновление и данные

Настройки и данные этой редакции находятся в `Data` рядом с EXE. Установщик
сохраняет существующий `Data/dictation.json`; его сценарий удаления также оставляет
пользовательские данные. Перед обновлением полезно сохранить собственный каталог `Data`.

Если в старых настройках ещё не было выбора режима «Дословно», он включится по
умолчанию. При свежей установке история аудио выключена. Старые Full/Qwen-компоненты
автоматически не удаляются и не обновляются.

## Проверка файла

Скачайте [SHA256SUMS.txt](https://github.com/egoist-ai1/EgoistVoice/releases/download/v2.2.1/SHA256SUMS.txt) и сравните результат:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\EgoistVoice-Setup-Russian-2.2.1-win-x64.exe'
```

Файл не подписан Authenticode. Контрольная сумма подтверждает совпадение с
опубликованными байтами, но не заменяет цифровую подпись издателя.

## Удаление и откат

Удалите Egoist Voice через установленные приложения Windows. Для отката сохраните
свои данные и выберите [предыдущий релиз](https://github.com/egoist-ai1/EgoistVoice/releases).
У старых установщиков политика сохранения данных может отличаться.

Полный цикл установки, обновления и удаления на чистой Windows для 2.2.1 ещё не
проверен; это ограничение сохраняется при публикации финального релиза по решению
владельца. [Примечания к релизу](releases/2.2.1.md).
