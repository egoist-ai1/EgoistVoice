# Change notes

Add one immutable note for every authorized project write-task, including saved
research and releases. Use UTC filename
`YYYY-MM-DDTHHMMSSZ-short-slug.md` and start from `_template.md`.

Never rewrite another task's note. Correct it with a new note that links the
old one. `INDEX.md` is generated; older hot notes move verbatim to
`archive/YYYY/MM/` and are never deleted by the history manager.
