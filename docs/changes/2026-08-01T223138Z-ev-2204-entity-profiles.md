# EV-2204 — profile-aware entity catalogue and exact boundary repair

- UTC: `2026-08-01T22:31:38Z`
- Ticket: `EV-2204`
- Production ASR decision: GigaAM baseline + conditional Whisper; hotwords HOLD

## What and why

Replaced the small global substitution list with versioned catalogue v2 across
AI/dev, apps/collaboration, operating systems, large companies, games/studios
and creative tools. The normal pipeline now derives a local technology/gaming
profile from the target process and utterance, then runs deterministic repair.

Unambiguous aliases remain global. `клауд/Cloud Code`, `кодекс`, `курсор`,
`мета` and `стим` require a matching profile and carry term-specific blockers
for ordinary language. Exact whitespace, hyphen, observed split and observed
join variants are supported; there is no fuzzy edit-distance rewrite. Canonical
Latin casing is repaired, and user dictionary entries still compile last.
