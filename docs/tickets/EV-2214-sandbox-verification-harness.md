# EV-2214 — оснастка проверки установщика Voice

- Status: `READY — EV-2209 package prerequisite passed; harness and guest runs not implemented`
- Specification: [Амендмент 002](../specs/002-voice-2.2-brand-ui-and-independence.md);
  нормативная матрица —
  [`SANDBOX-TEST-MATRIX.md`](../../../egoist-translator/docs/program/SANDBOX-TEST-MATRIX.md)
- Depends on: `EV-2209`, `EV-2200`
- Artifact boundary: только инструменты проверки и их доказательства. Ни один
  файл продукта не меняется.

## Наблюдаемый результат

Строки матрицы, относящиеся к установщику Voice, прогоняются одной командой в
Windows Sandbox и одной командой на снапшоте Hyper-V; результат — стандартный
каталог доказательств с `results.csv`, содержащим все относящиеся к Voice ID.

## Область и вероятные файлы

- Расширение существующих `scripts/test-installer.ps1`,
  `scripts/verify-staging.ps1`, `scripts/full-release-smoke.ps1` до формата
  доказательств из матрицы, а не написание параллельной оснастки с нуля.
- Новая конфигурация Windows Sandbox и скрипт прогона внутри гостя.
- Сбор `run.json`, `results.csv`, `evidence/<ID>/`, `summary.md`.
- Совместимость с оснасткой Translator `T021`: одинаковый формат
  доказательств, чтобы совместный прогон `EV-2213` + `T020` собирался в один
  отчёт.
- Исключено: изменение установщика ради удобства оснастки.

## Обязательные свойства

1. SHA-256 проверяемого `.exe` фиксируется до прогона и попадает в `run.json`.
2. Каждая строка стартует с чистого состояния; последовательный прогон без
   отката запрещён.
3. Снимки дерева файлов и экспорт ключей `Uninstall` — до и после каждой
   строки.
4. Оснастка не исправляет найденное, а помечает `fail`.
5. Ни в одном доказательстве нет аудио, распознанного текста и приватных
   путей.
6. Ограничения уровня Sandbox записываются явно: без моделей, без GPU,
   перевод проверяется только до состояния `ModelMissing`.

## Проверка

1. Прогон уровня `sandbox-tier` даёт заполненный `results.csv` со всеми
   относящимися к Voice ID.
2. Искусственно внесённый регресс установщика действительно приводит к `fail`
   соответствующей строки.
3. Два прогона на одних битах дают одинаковый набор вердиктов.
4. Формат доказательств совпадает с форматом Translator `T021` — проверено
   объединением двух отчётов в один.
