# EV-2212 — обновление интерфейса и состояний перевода

- Status: `APPROVED — inactive until EV-2207`
- Specification: [Амендмент 002](../specs/002-voice-2.2-brand-ui-and-independence.md) §2.2
- Depends on: `EV-2207`, `EV-2211`
- Artifact boundary: слой представления Voice. Захват звука, ASR,
  нормализация и разбор команд не меняются.

## Наблюдаемый результат

Каждое состояние движка перевода имеет честное видимое представление и
действие восстановления, а диктовка доказуемо работает при любом состоянии
движка, включая его полное отсутствие.

## Область и вероятные файлы

- `MainWindow.xaml`, `MainWindow.xaml.cs`, `MainWindow.Visuals.cs`,
  `Controls/**`, ресурсы стилей, значок и меню трея.
- Обязательный перечень состояний с отдельным видом и действием:
  `EngineMissing`, `EngineStarting`, `HandshakeFailed`, `ModelMissing`,
  `ModelDownloading`, `ModelVerifying`, `ModelStopped`, `ModelStarting`,
  `Ready`, `Translating`, `LongTranslation`, `Cancelled`, `EngineCrashed`,
  `IncompatibleContract`.
- Исключено: изменение контракта IPC ради удобства интерфейса, новые
  UI-зависимости, вмешательство в логику EV-2205.

## Свойство, которое проверяется отдельно

**Диктовка не зависит от перевода.** При каждом состоянии из перечня выше
запись, распознавание, нормализация и вставка текста продолжают работать.
Голосовая команда перевода при недоступном движке даёт честное короткое
уведомление и не ломает поток диктовки, не теряет уже надиктованный текст и не
вставляет служебные сообщения в целевое приложение.

## Границы приватности

- Ни одно новое место интерфейса не логирует распознанный или переведённый
  текст.
- Диагностические состояния показывают код и причину, а не содержимое.

## Проверка

1. Скриншот каждого состояния из перечня — рендер, а не описание.
2. Каждое состояние снято при 100/125/150/200 %, в светлой и тёмной теме.
3. Для каждого состояния выполнен прогон диктовки в Блокнот: текст вставлен
   корректно.
4. Проход по всем интерактивным элементам только с клавиатуры; фокус виден.
5. Экранный диктор озвучивает назначение элементов управления.
6. После полного прохода с текстом-канарейкой в логах ноль совпадений.
