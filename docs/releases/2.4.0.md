# Egoist Voice 2.4.0 — русская речь и оформление

Candidate source verified; publication and workstation replacement pending. 2.3.0 remains installed until final payload passes independent review.

Один офлайн-профиль теперь сохраняет слова plain GigaAM v3 RNNT и добавляет пунктуацию/заглавные буквы из E2E распознавания того же аудио. Известные английские названия получают canonical spelling только при безопасном подтверждении аудиомоделью. Настройка оформления включена по умолчанию; её выключение возвращает основной текст. При отказе оформления распознавание продолжает работать, а интерфейс сообщает «Вставлено без оформления».

Исправлены Unicode model paths, warmup/decode/dispose races и отмена. Тяжёлое планирование/чтение аудио выполняется вне WPF dispatcher. Подписи/диагностические состояния капсулы и настроек проверяются отдельно; существующая плавная bounded animation сохраняется. Восемь pinned моделей занимают 650090519 байт; Qwen/Whisper/GPU runtime не входят в Compact.

На 80 публичных записях ошибки пунктуации уменьшились на53.07%, raw surface errors на57.94%; lexical words26/1169 без изменения. Warm decode p50 вырос76→162мс. Full1037pass, Compact1030pass/7skip, silence/cancel/recovery/file-memory/111s/Unicode actual service pass. [Метрики и пределы](../models/EVALUATION-2.4.0.md).

Проверка личной сложной речи, реальных английских брендов и чистой Windows VM не выполнена. Не заявляется 50% рост lexical accuracy или скорости, свободное исправление смысла/орфографии и безошибочная интонация. Installer unsigned. Обновление рабочей установки выполняется транзакционным updater из проверенного payload с сохранением Data/настроек/истории; старый релиз2.3.0 остаётся доступен.

Native dependency is the official no-TTS shared MT v1.13.4 build, with the original GigaAM frontend and unchanged ONNX Runtime. Unused eSpeak/piper code is absent; all176 Sherpa exports remain. All80 full formatted outputs are identical to the earlier stock baseline. Binary hashes, upstream source/archive pins and full component notices are included in licenses/native-asr.
