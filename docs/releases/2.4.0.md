# Egoist Voice 2.4.0 — русская речь и оформление

[Версия 2.4.0 опубликована](https://github.com/egoist-ai1/EgoistVoice/releases/tag/v2.4.0) и установлена на рабочем компьютере. Source/tag: `61611dc58441e9b1395ba4ba63fc2845a9c7ebc4`. Последующая документация в main не меняет исходники и байты этого выпуска.

Один офлайн-профиль сохраняет слова plain GigaAM v3 RNNT и добавляет пунктуацию и заглавные буквы из E2E распознавания того же аудио. Известные английские названия получают точное написание только при безопасном подтверждении аудиомоделью. Оформление включено; его выключение возвращает основной текст. При отказе оформления распознавание продолжает работать, а интерфейс сообщает «Вставлено без оформления».

Исправлены Unicode-пути моделей, гонки warmup/decode/dispose и отмена. Планирование длинного аудио и чтение файлов выполняются вне WPF dispatcher. Проверены состояния капсулы и настроек; сохранена существующая ограниченная по ресурсам анимация. Восемь моделей занимают 650090519 байт. Qwen/Whisper/GPU runtime не входят в Compact: измеренные крупные кандидаты не дали достаточного выигрыша на выбранных русских записях.

На 80 публичных записях ошибки пунктуации уменьшились на 53.07%, ошибки символов с учётом регистра/знаков — на 57.94%; ошибки слов 26/1169 остались без изменения. Первый парный замер: медиана 76→162 мс; отдельно на точном опубликованном payload медиана 135.005 мс, p95267.8291 мс. Эти проходы не доказывают ускорение. [Метрики и пределы](../models/EVALUATION-2.4.0.md).

Независимо проверены 545 файлов/841125226 байт payload, API/UTF8 fork, Compact IL, native hashes, полные notices и hash guards. Silence, cancellation/recovery, file-memory, длинное аудио и Unicode native paths прошли.

Smoke фактически установленной EXE на публичной записи дал exit0 и точный принятый результат; личное аудио не использовалось. Все 160 plain/E2E raw outputs и 80 полных outputs совпали с прежним stock baseline. Hashes, source/archive pins и полные component notices входят в licenses/native-asr; побайтная самостоятельная пересборка upstream DLL не заявляется.

Личная сложная речь, реальные английские бренды, чистая акустическая разметка интонации и clean-Windows installer lifecycle не проверены. Не заявляются 50% рост точности слов, ускорение, свободное исправление смысла/орфографии или безошибочная интонация. Прямое перечисление live DLL недоступно из-за Windows ACCESS_DENIED5; точная EXE/файлы установки и native loads отдельного shipped harness проверены. Installer unsigned и на рабочем ПК не выполнялся: замена сделана из проверенного содержимого пакета. Предыдущий 2.3.0 остаётся доступен без изменения.
