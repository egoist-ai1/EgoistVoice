## User-visible result

Egoist Voice 2.2 adds a complete local translation path to the existing local dictation pipeline and ships every required ASR, GPU/CPU and shared translation component in one hash-bound payload set. The preferred 74 KB web installer downloads that exact set from this immutable GitHub release; the same files also form the Full Offline fallback.

## Web/offline bootstrap contract

- Local complete payload beside the bootstrapper always wins; no network is used.
- Otherwise files download into `%LOCALAPPDATA%\EgoistVoice\InstallerCache\v2.2.0-preview.1`.
- Interrupted `.part` downloads resume with HTTP `Range` when the server supports it.
- The release URL is pinned to `v2.2.0-preview.1`; `/latest` is not accepted.
- Redirects must remain HTTPS and land on approved GitHub asset hosts.
- Size and SHA-256 are checked before the inner installer starts.
- A missing, truncated or hash-mismatched file fails closed with exit code `1603`.
- Successful online installation removes the versioned download cache; failed installation keeps it for retry.

## Functional changes

- GigaAM remains RU primary; Whisper remains a conditional RU/EN fallback.
- Translation uses the pinned net8 client and exact shared Engine 1.0.0 / HY-MT2 Q8 / llama b10219 Vulkan pack.
- Dictation remains usable when the translation engine is absent or unavailable.
- Full Offline setup installs Host → pack → `egoist-voice` owner; uninstall removes only that owner and preserves shared data while another owner remains.
- Reported product-name variants normalize to `Egoist Voice` and `EGOIST Translator`.
- Strict inline punctuation works without rewriting ordinary «точка входа/доступа» phrases or dotted identifiers.

## Known limitations

- This release is unsigned. SmartScreen and Smart App Control may warn or block it.
- Exact clean install, repair, upgrade from 2.1.0, Voice + Translator coexistence and uninstall have not yet been executed in Windows Sandbox/Hyper-V for these bytes.
- The private 350-WAV corpus, device-removal endurance and the broader formatting matrix remain incomplete; no final SHIP or measured-accuracy claim is made.
- The installed `2.2.0` application confirms startup of its installed copy, not the lifecycle of the downloadable payload set.

## Rollback

Uninstall Egoist Voice from Windows Settings and reinstall [2.1.0](https://github.com/egoist-ai1/EgoistVoice/releases/tag/v2.1.0). User settings and dictionary live under `%LOCALAPPDATA%\EgoistVoice`; do not delete them for a normal rollback. Shared Translation Engine cleanup remains owner-aware and must not remove another EGOIST product's owner.
