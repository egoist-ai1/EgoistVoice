# Egoist Voice 2.3.0 — русская RNNT

GigaAM v3 plain RNNT INT8 заменяет E2E в одном офлайн-профиле CPU. Исправлено отклонение тихой речи, оптимизирована капсула и устранён фоновой выбор текстовой модели. Приложение и .NET 8.0.30 включены в офлайн-установщик.

Файлы релиза: `EgoistVoice-Setup-Russian-2.3.0-win-x64.exe`, `SHA256SUMS.txt`, `russian-payload.manifest.json`, `russian-installer.json`, `gigaam-v3-rnnt.json`, `public-pilot.json`.

Проверки исходников: Full 920 passed / 0 skipped; Compact 913 passed / 7 Full-only skipped; updater 12 сценариев, реальная isolated replacement и rollback; native decoder 40 парных human clips, официальный smoke, 100 одинаковых повторов, silence; визуальные состояния в фоне. Итоговые hashes/результаты выпуска находятся в manifest и release verification receipt.

[Публичные измерения и пределы](../models/EVALUATION-2.3.0.md). Обычная RNNT выдаёт слова без встроенной E2E пунктуации. Английские названия вторичны. Персональный голосовой корпус не проверен, чистая Windows VM недоступна; полный installer lifecycle не объявляется пройденным. Неподписанный установщик. Исторический Full EV-2210 остаётся отдельной незавершённой программой.

Обновление рабочего компьютера выполняется `scripts/Update-CompactInstallation.ps1` из hash-verified final payload. Скрипт привязывает точный процесс/каталог, завершает текущую диктовку до остановки, сохраняет Data/неизвестные файлы и пользовательские предпочтения, выбирает русский дословный профиль, ждёт реальную готовность RNNT. При ошибке восстанавливает предыдущие изменённые файлы и настройки. Установщик на рабочем компьютере для теста не запускается.
