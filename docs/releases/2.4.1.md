# Egoist Voice 2.4.1 — Windows, микрофон и фоновая работа

[Релиз 2.4.1](https://github.com/egoist-ai1/EgoistVoice/releases/tag/v2.4.1) опубликован 02.10.2026 и установлен на рабочем компьютере. Исходник пакета и тег: `66f79ad5c352b7e648b17f4492802a851eaa8c2c`. Сохранена GigaAM v3: plain RNNT INT8 для слов и E2E RNNT INT8 для пунктуации/регистра, последовательно на CPU, по четыре потока.

Операции захвата и устройств выполняются вне UI dispatcher с отслеживаемым завершением и защитой от устаревших callbacks. Микрофон по умолчанию Windows выбирается заново при начале записи; временная потеря устройства учитывается отдельно от ручной паузы. Скрытые/свёрнутые окна отключают лишние кадры, таймеры и повторяющиеся анимации. Настройки сохраняют громкость при быстром закрытии. Исправлен запуск с отключёнными анимациями Windows; звуковой start cue больше не подавляет первый аудиоблок.

Известные русские названия, слитные предлоги и отдельные явные сокращения исправляются только при подтверждении второй аудиомоделью и двумя неизменными опорными словами. Неизвестные слова и окончания не угадываются. 191 текстовый тест/41 новый; public80 replay побайтно прежний:26 ошибок слов/130 пунктуации/241 raw-character.
