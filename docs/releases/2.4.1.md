# Egoist Voice2.4.1 — Windows, микрофон и фоновая работа

Кандидат готовится к публикации и установке; эти действия ещё не завершены. Используется прежняя локальная GigaAM v3: plain RNNT INT8 для слов и E2E RNNT INT8 для пунктуации/регистра, CPU4, без новых моделей.

Native операции и переключение микрофона выполняются вне UI dispatcher с отслеживаемым завершением. Default-режим берёт актуальный микрофон Windows при каждом запуске записи; временная потеря устройства не превращается в пользовательскую паузу. Устаревшие callbacks и отменённые окончания записи отсеиваются по поколениям.

Скрытая/свёрнутая капсула отключает лишние кадры и повторяющиеся анимации. Настройки приостанавливают ненужные таймеры, убирают старые переходы и сохраняют громкость при быстром закрытии. Начальный звуковой cue во время активной записи не подавляет первый аудиоблок.

Ограниченные текстовые правила исправляют известные русские названия, слитные предлоги и отдельные явно подтверждённые сокращения. Неизвестные слова и окончания не угадываются. На public80 прежние outputs сохранены побайтно:26слов/130ошибок пунктуации/241raw-character.
